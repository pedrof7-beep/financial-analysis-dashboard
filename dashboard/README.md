# Dashboard folder

Esta pasta pode ser usada para guardar o ficheiro final do dashboard em Power BI (.pbix), screenshots do dashboard, e qualquer material adicional para apresentação.

## Recomendação
- guardar uma versão final do dashboard com filtros interativos;
- incluir imagens de KPI cards, gráficos de tendência e comparações por empresa;
- manter também uma versão de apresentação para entrevistas e networking.

## Estrutura sugerida
```text
dashboard/
├── screenshots/
├── exports/
├── Financial_Performance_Dashboard.pbix
└── README.md
```
